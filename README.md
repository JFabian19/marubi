# MARUBI — E-Commerce Storefront

Plataforma de comercio electrónico Direct-to-Consumer (DTC) para herramientas y equipamiento de precisión, optimizada para tráfico social y conversión en el mercado peruano.

## 🛠️ Productos Destacados

1. **Mini Amoladora Inalámbrica 48V + 2 Baterías y Kit Completo** — `S/ 119` (Producto Principal)
2. **Taladro Percutor Inalámbrico 180V con 2 Baterías y Kit Completo** — `S/ 130`
3. **Taladro Percutor Inalámbrico 180V + Kit Profesional de Herramientas** — `S/ 180`
4. **Kit de Destornilladores de Precisión 115 en 1** — `S/ 99`
5. **Sopladora Turbo Inalámbrica 35,000 Pa – Violent Fan JH-801** — `S/ 69`

## 🌟 Características

- **Diseño DTC Moderno:** Paleta corporativa `#001737` y `#062C59` con acento de conversión naranja `#FF6126`.
- **Hero Animado:** Curva editorial `cubic-bezier(0.16, 1, 0.3, 1)`, secuencia escalonada (*staggered entrance*) y levitación `subtleFloat`.
- **Bolsa de Compras Interactiva:** Slide-over drawer con cálculo de totales en tiempo real, persistencia local y soporte para pedidos directos vía WhatsApp.
- **Checkout Seguro:** Integración con WhatsApp y pasarela simulada con Yape/Plin, Tarjeta y Contraentrega.
- **Rastreo de Pedidos:** Módulo de consulta de envíos en 24h a nivel nacional.
- **Modo Móvil / Escritorio:** Conmutador flotante para probar vistas.

## 🚀 Despliegue Local

Simplemente abre `index.html` en tu navegador o ejecuta:

```bash
python -m http.server 8080
```
